doc_id: doc_29
topic: HTML

## What is SEO?
SEO stands for Search Engine Optimization. It helps your page rank higher in Google search results.

## Important Meta Tags
<meta name="description" content="Learn web development with ATX WebDevQuizy">
<meta name="keywords" content="HTML, CSS, JavaScript, web dev quiz">
<title>ATX WebDevQuizy - Learn Web Dev</title>

## Heading Hierarchy
Use only one h1 per page. It should describe the main topic.
h1 > h2 > h3 in order — do not skip levels.

## Semantic HTML for SEO
Search engines read semantic tags to understand your content.
Use article, section, nav, header, footer properly.

## Image Optimization
- Always add alt text to images
- Use descriptive file names: css-flexbox-diagram.png not img001.png
- Compress images to reduce load time

## Page Speed
Fast pages rank higher. Tips:
- Minify CSS and JavaScript files
- Use compressed image formats like WebP
- Avoid too many external scripts

## Open Graph Tags
For social media previews:
<meta property="og:title" content="ATX WebDevQuizy">
<meta property="og:image" content="preview.png">
